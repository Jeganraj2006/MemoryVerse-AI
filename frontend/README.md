# MemoryVerse AI Frontend

React/Vite interface for the Evidence-Backed Career Passport.

## Run locally

```bash
npm install
copy .env.example .env
npm run dev
```

Configure `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`. The Vite development server proxies `/api` to `http://localhost:8000`.

Main experiences:

- private document and GitHub ingestion;
- career timeline and evidence knowledge graph;
- cited Graph-RAG chat;
- explainable Skill Evidence Passport;
- quality dashboard and revocable portfolio sharing.
